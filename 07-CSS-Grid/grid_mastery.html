Grid Property Cheat Sheet

  • grid-template-columns / rows: Establishes the layout. Use fr (fractional units) to divide free space.
  • repeat(count, size): Keeps CSS dry. repeat(4, 1fr) creates 4 equal columns.
  • minmax(min, max): Creates responsive boundaries without media queries.
  • auto: Sizing behaves like standard block elements—dictated by the content inside.
  • grid-auto-rows / columns: The safety net. It sizes implicit grid items (items created outside your defined template).
  • gap: Pure spacing between items. Replaces hacky margin math.
  • grid-column / grid-row: Shorthand to place items using grid lines. Format is start / end.
  • span: Used inside placement to stretch across tracks (e.g., span 3).
  • grid-area: The master shorthand for manual placement: row-start / column-start / row-end / column-end.
  • order: Moves items visually. Lower numbers appear first.
